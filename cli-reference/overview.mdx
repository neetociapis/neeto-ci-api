## Global flags

These flags work on every command and are left out of the per-command flag tables below. See [Output formats](/cli/output-formats) for details.

| Flag | Description |
| --- | --- |
| `--json` | Output as JSON |
| `--quiet` | Output raw data only (no envelope) |
| `--toon` | Output in TOON format (token-optimized for AI agents) |
| `--subdomain` | Override saved subdomain |

### ci-jobs

Manage CI jobs

| Command | Description |
| --- | --- |
| [`neetoci ci-jobs cancel`](/cli-reference/ci-jobs#cancel-a-ci-job) | Cancel a running CI job |
| [`neetoci ci-jobs create`](/cli-reference/ci-jobs#trigger-a-ci-job) | Trigger a new CI job |
| [`neetoci ci-jobs list`](/cli-reference/ci-jobs#list-ci-jobs) | List CI jobs for a project |
| [`neetoci ci-jobs logs`](/cli-reference/ci-jobs#show-ci-job-logs) | Show the per-pod logs of a CI job |
| [`neetoci ci-jobs rerun`](/cli-reference/ci-jobs#rerun-a-ci-job) | Rerun a CI job |
| [`neetoci ci-jobs resource-metrics`](/cli-reference/ci-jobs#show-resource-metrics) | View a CI job's per-pod CPU and memory metrics (for debugging OOM/perf) |
| [`neetoci ci-jobs show`](/cli-reference/ci-jobs#show-a-ci-job) | Show a CI job |
