A project is a GitHub repository connected to NeetoCI. Its `name` is the value every `--project` flag takes. Sample outputs on this page use `--json`.

## List projects

This command shows the active projects in your workspace, sorted by name. Use this when you need a project's name for `ci-jobs list` or `ci-jobs create`, or to check which repositories are connected.

```bash
neetoci projects list
neetoci projects list --page 2 --page-size 50
```
